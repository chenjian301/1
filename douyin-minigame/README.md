# 抖音小游戏工程（竖屏 · 无限地图 · 自动战斗 · 刷宝）

> 这是**可以直接用抖音开发者工具打开的工程本体**：入口是 `game.js`，配置是 `game.json`，
> 不需要 npm / 不需要构建工具 / 不需要联网。角色、地图与**声音**都是程序生成/自绘的
> （没有贴图 / 图集，也没有外部音频素材 —— 那是阶段 E 的事）。
>
> 数值的唯一真相是仓库根的 `shared/balance.json`；本目录的 `src\01-balance.js` 是它**生成**出来的。

## 二、怎么玩

| 操作 | 说明 |
|---|---|
| 左下拖动 | 浮动摇杆：按下即出现，圆心就是按下点；推得越满走得越快 |
| 攻击 | **没有攻击键** —— 自动战斗：每 0.1 秒选"视野内最近"的怪，进了 72 距离就按攻速出手 |
| 右下「自动」 | **自动战斗开关**：开启后会自动走向视野内最近的怪（走到攻击距离站住）；摇杆一推就手动优先 |
| 右下「箱」 | 开箱（六阶宝箱 / 保底计数 / 开出来自动对比战力并穿上更强的） |
| 右下「包」 | 背包与装备（一键分解：每个部位只留最强 1 件，其余换金币） |
| 右下「会」 | 公会（20 级 + 号角可建会；锚点在你脚下，可一键回城） |
| 右下「营」 | **只在营地里出现**：治疗（按缺失血量收金币）/ 进商城 / 回营地中心 / 回公会锚点 |
| 右下「设」 | 自检 / 云后端连通性 / **音效·背景音乐·震动开关** / 调试面板 / 重置存档 |
| 面板 | **只占约 1/3 屏**，右上角 ✕ 关闭（再点一次同一个功能键也能收起）；内容长了在卡片内上下拖动滚动；**面板开着游戏不停止**，卡片外面照旧能推摇杆走位 |

设计意图（`docs\design\01-game-design.md`）：操作只剩"移动"，成长做成没有上限的线，
越往外走怪越强、箱子越好 —— 这就是无限地图的意义。

## 三、现在已经能跑的内容（阶段 A2 + A3 + A4 完成）

- **账号与角色（A4）**：标题 → 登录 → 创建角色三块屏；登录优先走抖音账号（`tt.login` → 服务端
  `code2session`），任何一环失败都降级成**本机离线账号**（绝不因网络卡住进游戏）；
  昵称 2~12 个字符（中文 / 字母 / 数字 / 下划线），**两层去重**：本机注册表 + 服务端 `POST /api/name`
- **确定性无限地图**：chunk = 坐标的函数；同坐标全世界看到同一片地（指纹 `e9802f11` 锁死）
- 五套地形主题（草原 → 荒漠 → 雪原 → 焦土 → 虚境，再往外只做色偏）、每 chunk 8~24 个装饰、每 5×5 chunk 一个地标
- **简单角色（A3）**：玩家是自绘小人（八方向朝向、走路摆腿摆臂、出手挥砍、受击闪红、倒地躺平）；
  4 种怪各有造型（荒狼四足 / 血蝠扇翅 / 游魂法师长袍法杖 / 重甲兵宽躯干大锤），精英戴金冠。
  动画相位只由**逻辑时间**推出来（不用 `Date.now`），所以逻辑依旧可重放、可在 node 里断言
- **地图设计（A3）**：原点**新手营地**（石砖地 + 木围栏留门 + 篝火 / 帐篷 / 旗 / 木牌 / 木箱 / 树桩）、
  **小径路网**（每 6 个 chunk 一个节点，连成带环的网，出生点附近就是路口）、装饰按主题换造型
  （阔叶 / 仙人掌 / 松树 / 枯木 / 水晶）、地标重绘为废墟与石碑、右上角**小地图**
  （chunk 网格 + 小径 + 营地 + 地标 + 怪 + 公会锚点 + 你的朝向）
- **4 种怪**（荒狼 / 血蝠 / 游魂法师 / 重甲兵）+ 8% 概率精英（血 ×5）；怪会游荡、仇恨、追击、脱战回家、15~30 秒重生
- **自动战斗**：视野内最近选目标（同距取 ID 小）、攻速 1.6 次/秒、暴击、击退、飘字、伤害归属
- **经验与升级**：`need(L) = 150×L^1.5`（1→20 约 10 万经验）；击杀经验/金币按 band 加成，精英 ×5 / ×8
- **六阶宝箱**：普通怪 8%+band×1%（上限 20%）、精英 25% 且不低于专家箱；**保底 50 箱必出史诗、500 箱必出神话**；背包 200 上限（满了自动分解）
- **装备系统**：6 部位 × 6 等阶，词条数 1/2/3/4/5/5+天赐专属，主属性随**掉落等级**成长（越远越强）、战力一键对比
- **本地存档**：角色名/等级/经验/金币/宝箱与保底/已穿装备/背包/位置/公会/设置/营地冷却；每 5 秒 + 切后台自动存；
  重置存档要两次点击确认（**角色名保留**）。存档格式 `v2`，v1 存档会被**就地迁移**（等级金币装备一件不丢）
- **HUD（A4）**：左上角头像（程序自绘，由角色名与等级推出）+ 角色名 + 等级 + 血条 + 金币/战力/自动战斗状态；
  玩家头顶**角色名 + 血条**；**画面最下方经验条**；右上角小地图
- **自动战斗按钮（A4）**：右下「自动」是开关（状态随存档），开启后自动走向视野内最近的怪、
  进攻击距离站住；摇杆一推就手动优先。真正的**技能系统没有做**（`01-game-design.md` §12 的"不做"清单）
- **打击感（A4）**：每次出手一道斩击弧（暴击多四道光刺）；命中顿帧 45ms / 暴击 110ms / 挨打 30ms；
  暴击震屏 + 短震动（`view.hitStopMs / view.shake`）
- **音效与 BGM（A4）**：8 个音效 + 1 条 8 秒循环 BGM，全部由 `tools\gen-minigame-sfx.mjs` **合成**到
  `audio\`（共 304KB，不引入任何外部素材）；设置面板可分别关音效 / BGM / 震动，改完立刻生效
- **营地交互入口（A4）**：站在营地里右下多一个「营」—— 治疗（按缺失血量收金币）/ 进商城 /
  回营地中心（10 秒冷却、战斗中禁用）/ 回公会锚点。营地**仍然不影响刷怪**（A3 的取舍没变）
- **商城与公会（本地版）**：20 级解锁，号角 500 金币；建会消耗号角、锚点 = 建会位置、回城有冷却且战斗中禁用
- **调试与自检**：设置面板可跑 **385 项断言**（含冒烟渲染），调试面板显示 FPS / chunk 数 / 活跃怪 / 当前目标 / 世界种子

**还没做**（按路线图往后排）：贴图与图集（现在的角色与地图都是**程序自绘**，只有走 / 砍 / 扇翅这类基础表现）、
技能系统（自动战斗目前 = 自动走位 + 自动出手）、客户端预测与服务端联机（阶段 B/C：云存档 / 全服共享怪 / 附近玩家）、
公会服务端（阶段 D）、图集分包与提审材料（阶段 E）。

**A4 里两条没能在本机验证的事**（真机首次测试时专门看一眼）：
① 昵称输入走 `tt.showKeyboard`，模拟器里没有键盘时会自动落到"随机昵称 + 换一个"的兜底路径；
② 音频要首次触摸后才解锁，模拟器与真机的表现可能不同。

## 五、四道验证关 + 一把性能尺子（为什么敢不写 web 端）

决策 #7 定了"只做小游戏端"，代价是失去浏览器端到端 harness。这里用前四道补回来，
再留一把尺子防止"改外观把绘制量画翻倍"：

1. **`tools\check-minigame.ps1`（静态）**：配置能否解析、`game.js` 是否与 `src\` 同步（哈希）、
   `01-balance.js` 是否与 `balance.json` 同步（哈希）、有没有 DOM/browser API、`tt.` 是否只在平台层、
   有没有 `Math.random` / `Math.hypot`、三角函数是否跑进了"必须无三角"的文件、`Date.now` 是否只在平台/入口、
   模块名是否撞车、**音频清单里的文件是否都在磁盘上**（路径写错 = 永久静音，逻辑断言看不见这种错）、
   生成文件头是否为 ASCII（PS 5.1 会把非 ASCII 的 .ps1 写成乱码 —— 踩过）。
2. **`19-selftest.js` + `tools\minigame-selftest.mjs`（逻辑）**：385 项断言，覆盖数值表、chunk 数学、
   地形/装饰、怪与地标播种、**营地几何与小径路网**、经验金币曲线、伤害/暴击/选目标/奖励归属、掉箱与保底、
   装备生成与战力、玩家属性/移动/死亡复活、本地存档、**账号与昵称（含 v1→v2 迁移）**、
   **界面卡片与登录界面的 action**、**自动战斗走位**、**打击感（顿帧/震屏/特效）**、**音频开关**、
   **营地交互（治疗/传送）**、朝向映射与走路/挥砍相位，以及**世界指纹**。
3. **冒烟渲染（同一个自检里）**：用一个"假 canvas 上下文"跑 `boot → 2100 步（走 10 秒 + 站桩 25 秒）→ 31 帧`，
   断言能进画面、能移动、能打死怪、能升级、坐标没有 NaN、绘制调用不为 0 ——
   专门防"静态检查全过、一进游戏白屏"（上一版真踩过）。
4. **`tools\perf-frame.mjs`（性能尺子，不是拦截门）**：用一个自记账的假 canvas 逐层数"落笔"次数
   （fill / stroke / fillRect / fillText，不含建路径的 moveTo/lineTo）。A4 实测最坏 **775 / 上限 900**
   （营地 + 调试面板），逐层拆分见 `docs\design\02-architecture.md` §9。换外观 / 加特效后跑一下，
   能在"手感变卡"之前发现是哪一层涨了。

游戏内也能验：右下「设」→「立即跑自检」，结果与指纹直接摆在屏幕上。

### 世界指纹是什么

`19-selftest.js` 里的 `worldFingerprint(seed)` 把原点附近 3×3 chunk 的怪 + 装饰 + 地标压成一个整数，
基准值是 **`e9802f11`**，与 `src\` 里 TypeScript 版 `tools\test-logic.mjs` 的基准**必须逐位相同**。
它是"JS 移植有没有偷偷漂移"的唯一尺子：任何一处改动让三角函数进了哈希、把整数换成浮点、
或者两边只改了一边，这个值立刻变。（模拟器/V8 上应当一致；真机若是别的引擎，
最后几位可能有差异，那时以模拟器 + 真机观感为准。）

## 六、后端（抖音云）

阶段 A **完全不联网**：`00-config.js` 的 `cloudBase` 留空时，`G.PLAT.cloud()` 直接 reject，一个包都不发。
部署好抖音云服务后，把控制台给的访问域名粘到 `cloudBase`（末尾不带斜杠），然后在
「设 → 云后端连通性自测」点一下，会调一次 `/api/health` 并把结果显示在屏幕上。

服务端代码与完整步骤见：`douyin-cloud\` 与 **`docs\douyin-cloud-deploy.md`**。
把代码送上去之前先在本地过一关：`powershell -ExecutionPolicy Bypass -File tools\cloud-pack.ps1`
（真起进程打 41 项断言，过了才产出可上传的 zip）。把代码送上去那一步：抖音云没有官方 CLI，
现在的「服务设置 → 部署方式」里只有 **模板部署 / git部署 / 镜像部署**，首选 **git部署**
（从 GitHub 拉代码构建；先按 `docs\douyin-cloud-deploy.md` §2.5 把仓库推上去，再按 §2.6 填表）。

**登录这件事服务端已经接好了（2026-09-30）**：`POST /api/profile` 用真 `code2session` 把 `tt.login` 的
`code` 换成 openid，并签发自己的 HMAC 令牌（无状态：重新部署 / 多实例都不掉线）；`/api/save` 有令牌时
**只认令牌里的账号**，客户端直接给的 `openid` 一律忽略（冒烟测试里"越权写 / 伪造签名 / 过期令牌"三项
就是钉这条的）。客户端那一半（`G.PLAT.login()` 包 `tt.login`、把 token 存下来、请求带 `Authorization`）
还没接 —— 它没法在 node 里自测（`tt.login` 只在真机 / 开发者工具里存在）。
