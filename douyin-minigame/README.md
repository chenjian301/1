# 抖音小游戏工程（竖屏 · 无限地图 · 自动战斗 · 刷宝）

> 这是**可以直接用抖音开发者工具打开的工程本体**：入口是 `game.js`，配置是 `game.json`，
> 不需要 npm / 不需要构建工具 / 不需要联网。角色、地图与**声音**都是程序生成/自绘的
> （没有贴图 / 图集，也没有外部音频素材 —— 那是阶段 E 的事）。
>
> 数值的唯一真相是仓库根的 `shared/balance.json`；本目录的 `src\01-balance.js` 是它**生成**出来的。

## 二、怎么玩

| 操作 | 说明 |
|---|---|
| 左下拖动 | 浮动摇杆：按下即出现，圆心就是按下点；推得越满走得越快。**触发区下边 = 底部动作栏的顶边**（A7 修订），所以按键那一片不会顺手起摇杆 |
| 攻击 | **没有攻击键** —— 自动战斗：每 0.1 秒选**全地图最近**的怪（`combat.targetRange = 0` = 不限距离），进了 72 距离就按攻速出手 |
| 技能键（四个） | **横扫 / 疗愈 / 穿刺 / 旋风**：点一下放，各有冷却 + 300ms 公共冷却；没到等级（Lv.1 / 4 / 7 / 10）画成「锁」。**最底那一行**就是它们（A7）。**右上角的勾选框 = 自动释放开关**（A10）：勾上才会被自动战斗放出去，没勾的只手动放 |
| 底部「自动」 | **自动战斗开关**：开启后会自动走向**全地图最近**的怪（走到攻击距离站住），**并自动放技能**（只放勾上了"自动释放"的那几个）；摇杆一推就手动优先 |
| 底部「箱」 | 开箱：**两个大按钮**（开 1 / 开 10）+ **两条保底进度条**（差几箱必出史诗 / 神话）+ **六阶宝箱清单**（A13，用户："宝箱背包不需要格子，直接放不同等阶宝箱×数量"：一阶一行 = 阶色箱子 + 阶名 + **× 数量** + 掉落占比，恒六行，**没有的阶也占一行**）；**每一行右侧还有两枚按阶控件**（A14，用户："宝箱可以设置是否自动开启——对应不同等阶不同的开启按钮"）：一枚**阶色**的「全开」按钮（开掉**这一阶**的全部箱子；这一阶 0 口箱时压淡、点了没反应）+ 一枚「自动」勾选（勾上 = 这一阶**掉出来就当场开**，不进背包、不占 200 口上限）；开出来自动对比战力并穿上更强的 |
| 底部「包」 | **背包 / 装备**：上方**角色预览**（四角四个装备槽 —— 左上武器 / 右上衣服 / 左下鞋子 / 右下饰品，点一下脱下）+ **技能自动释放条**（点一下切换）+ **三排五列背包格**（点一下穿上：比身上强的画绿↑、等级不够的压淡；**A15 起一页 15 件、在格子上上下拖翻页**看全部 200 件 —— 拖过就不算点击）+ 两个大按钮（一键分解 / 角色属性）+ **属性网格**（图标 + 名称 + 数值） |
| 底部「会」 | 公会（20 级 + 号角可建会；锚点在你脚下，可一键回城） |
| 底部「商」 | **商城（A15）**：号角 500 金币 + **强化石 100 金币一颗**（铁匠强化用）；角标 = 手里的强化石数（20 级解锁） |
| 底部「营」 | **只在营地里出现**（占最左那个固定槽位）：治疗（按缺失血量收金币）/ 进商城 / **找铁匠强化装备（A15）** / 回营地中心 / 回公会锚点 |
| 营地铁匠（A15） | 篝火旁边那个铁砧：**走到他跟前**屏幕上会多一枚「锻」键（走远自动消失），点它开强化面板 —— 给**身上穿着的四件**逐级强化（+1 → +10，成本 1 / 2 / 4 / … / 512 颗强化石，每级主属性 +10%、+10 正好翻倍）；营地面板里那一行「找铁匠强化装备」是同一个面板 |
| 底部「设」 | **角色属性** / **视角缩放滚动轴（A11 之二：拖动滑块，一屏 16 ~ 64 格，整格走）** / 自检 / 云后端连通性 / **音效·背景音乐·震动开关** / 调试面板 / 重置存档 |
| 面板 | **约 2/3 屏高**（2026-10-01 从"约 1/3 屏"调高，为的是少滚），右上角 ✕ 关闭（再点一次同一个功能键也能收起）；内容长了在卡片内上下拖动滚动；**面板开着游戏不停止**，卡片外面（尤其底部整条动作栏）照旧能推摇杆走位、按功能键。A10 起背包 / 宝箱 / 属性是**版面**（角色预览 / 格子 / 进度条 / 图例），不再是一列一列的字 |

设计意图（`docs\design\01-game-design.md`）：操作只剩"移动"，成长做成没有上限的线，
越往外走怪越强、箱子越好 —— 这就是无限地图的意义。

## 三、现在已经能跑的内容（阶段 A2 + A3 + A4 + A5 + A6 + A7 + A8 + A9 + A10 + A11 完成）

- **账号与角色（A4）**：标题 → 登录 → 创建角色三块屏；登录优先走抖音账号（`tt.login` → 服务端
  `code2session`），任何一环失败都降级成**本机离线账号**（绝不因网络卡住进游戏）；
  昵称 2~12 个字符（中文 / 字母 / 数字 / 下划线），**两层去重**：本机注册表 + 服务端 `POST /api/name`
- **确定性无限地图**：chunk = 坐标的函数；同坐标全世界看到同一片地（指纹 `e9802f11` 锁死）
- 五套地形主题（草原 → 荒漠 → 雪原 → 焦土 → 虚境，再往外只做色偏）、每 chunk 8~24 个装饰、每 5×5 chunk 一个地标
- **简单角色（A3）**：玩家是自绘小人（八方向朝向、走路摆腿摆臂、出手挥砍、受击闪红、倒地躺平）；
  4 种怪各有造型（荒狼四足 / 血蝠扇翅 / 游魂法师长袍法杖 / 重甲兵宽躯干大锤），精英戴金冠。
  动画相位只由**逻辑时间**推出来（不用 `Date.now`），所以逻辑依旧可重放、可在 node 里断言
- **地图设计（A3）**：原点**新手营地**（石砖地 + 木围栏留门 + 篝火 / 帐篷 / 旗 / 木牌 / 木箱 / 树桩）、
  **小径路网**（每 6 个 chunk 一个节点，连成带环的网，出生点附近就是路口）、装饰按主题换造型
  （阔叶 / 仙人掌 / 松树 / 枯木 / 水晶）、地标重绘为废墟与石碑、右上角**小地图**
  （chunk 网格 + 小径 + 营地 + 地标 + 怪 + 公会锚点 + 你的朝向）
- **4 种怪**（荒狼 / 血蝠 / 游魂法师 / 重甲兵）+ 8% 概率精英（血 ×5）；怪会游荡、仇恨、追击、脱战回家、15~30 秒重生
- **自动战斗**：**全地图最近**选目标（`combat.targetRange = 0` = 不限距离；同距取 ID 小）、攻速 1.6 次/秒、暴击、击退、飘字、伤害归属
- **经验与升级**：`need(L) = 150×L^1.5`（1→20 约 10 万经验）；击杀经验/金币按 band 加成，精英 ×5 / ×8
- **六阶宝箱**：普通怪 8%+band×1%（上限 20%）、精英 25% 且不低于专家箱；**保底 50 箱必出史诗、500 箱必出神话**；背包 200 上限（满了自动分解）
- **装备系统（A6 起是目录驱动）**：**四个部位**（武器 / 衣服 / 鞋子 / 饰品）× **六阶各 10 件 = 60 件**有名有姓的装备。
  每件有**自己的等级门槛**（`1 + (阶-1)×3 + floor(阶内序号/4)`，1 阶 Lv.1~3、6 阶 Lv.16~18），**等级不够穿不上**
  （开箱的自动穿会跳过、手动点会被拒）；同阶内越靠后越强（+2%/件）。穿什么就像什么：武器 8 种造型、
  衣服 6 种款式、鞋 4 种、饰品 4 种（含配色）**画在角色身上**，同一份数据在背包里画成**内观图标**（阶色边框）
- **六阶的发光色（用户：给不同等阶的装备添加发光颜色，分别为白色，蓝色，紫色，金色，红色，炫彩）**：
  一阶一个颜色（`balance.equipment.tiers[].glow`：**白 / 蓝 / 紫 / 金 / 红 / 炫彩**，末阶是一串颜色），
  装备格 / 背包格 / 宝箱清单的行图标（A13 起，取代原来的箱子格与六阶图例）外面都描一圈**会呼吸的**发光环（往外 `layers` 层、越外越淡），
  末阶的炫彩随时间换色流动；背包面板**角色预览**背后那束光取身上**最高那一阶**的颜色（光身板就没有）。
  画法规格在 `balance.view.iconGlow`（关掉 `enabled` 就退回「只有阶色描边」，自检验这一条）
- **宝箱背包按阶汇总（A13，用户："宝箱背包不需要格子，直接放不同等阶宝箱×数量"）**：开箱面板里**不再有格子** ——
  一阶一行（普通 → 天赐），每行 = 阶色小箱 + 阶名 + **× 数量** + 掉落占比；**没有的阶也占一行**（压淡写 × 0），
  于是"还缺哪一阶"一眼看得出，**200 口箱也不会截断**（旧版格子只列得下前 12 个）。
  数量由 `08-loot.js` 的 `countByTier(chests)` 数出来（与袋子里的先后顺序无关），掉落占比仍是从
  `balance.chests.tiers[].weight` 算出来的；清单**只读**（开箱只走上面那两个大按钮）。
- **按阶开箱与按阶自动开启（A14，用户："宝箱可以设置是否自动开启——对应不同等阶不同的开启按钮"）**：
  六阶清单**每一行右侧**两枚控件，颜色就是**这一阶的阶色**（六行六色，一眼分得清点的是哪一阶）——
  ① 一枚「全开」按钮（`openChestsOfTier`：把**这一阶**的箱子一次开完，别的阶一口不动；这一阶 0 口箱时
  压淡且**不产出 action**）；② 一枚「自动」勾选（存档 `settings.chestAuto`，一阶一枚、**默认全关**）。
  勾上「自动」的那一阶：箱子**掉出来就当场开**（`autoOpenChest`）—— 不进背包、于是**不吃 200 口上限**、
  也不会碰到"背包满了自动分解"；开出来的装备与手点开箱**完全同一条规则**（更就穿，否则进背包）。
  清单**行身仍然只读**（点那一行的字什么都不发生）："按阶开箱"只走那枚显式按钮，不会出现"点传说开出来是普通箱"。

### 世界指纹是什么

`19-selftest.js` 里的 `worldFingerprint(seed)` 把原点附近 3×3 chunk 的怪 + 装饰 + 地标压成一个整数，
基准值是 **`e9802f11`**，与 `src\` 里 TypeScript 版 `tools\test-logic.mjs` 的基准**必须逐位相同**。
它是"JS 移植有没有偷偷漂移"的唯一尺子：任何一处改动让三角函数进了哈希、把整数换成浮点、
或者两边只改了一边，这个值立刻变。（模拟器/V8 上应当一致；真机若是别的引擎，
最后几位可能有差异，那时以模拟器 + 真机观感为准。）

## 六、后端（抖音云）

阶段 A **完全不联网**：`00-config.js` 的 `cloudBase` 留空时，`G.PLAT.cloud()` 直接 reject，一个包都不发。
部署好抖音云服务后，把控制台给的访问域名粘到 `cloudBase`（末尾不带斜杠），然后在
「设 → 云后端连通性自测」点一下，会调一次 `/api/health` 并把结果显示在屏幕上。

服务端代码与完整步骤见：`douyin-cloud\` 与 **`docs\douyin-cloud-deploy.md`**。
把代码送上去之前先在本地过一关：`powershell -ExecutionPolicy Bypass -File tools\cloud-pack.ps1`
（真起进程打 82 项断言，过了才产出可上传的 zip）。把代码送上去那一步：抖音云没有官方 CLI，
现在的「服务设置 → 部署方式」里只有 **模板部署 / git部署 / 镜像部署**，首选 **git部署**
（从 GitHub 拉代码构建；先按 `docs\douyin-cloud-deploy.md` §2.5 把仓库推上去，再按 §2.6 填表，
最后 §10 是这一版**公会接口**的上线三步）。

**登录这件事服务端已经接好了（2026-09-30）**：`POST /api/profile` 用真 `code2session` 把 `tt.login` 的
`code` 换成 openid，并签发自己的 HMAC 令牌（无状态：重新部署 / 多实例都不掉线）；`/api/save` 有令牌时
**只认令牌里的账号**，客户端直接给的 `openid` 一律忽略（冒烟测试里"越权写 / 伪造签名 / 过期令牌"三项
就是钉这条的）。客户端那一半（`G.PLAT.login()` 包 `tt.login`、把 token 存下来、请求带 `Authorization`）
还没接 —— 它没法在 node 里自测（`tt.login` 只在真机 / 开发者工具里存在）。

**公会接口（2026-10-01 新增）**：`/api/guild/create|join|leave|anchor|mine|list` 六个端点，
服务端是**权威** —— 名字全服唯一、**公会等级由服务端按成员等级之和算**（
`1 + floor(Σ成员等级 / 100)`，封顶 10；成员等级直接读 `saves` 表里那份存档，客户端伪造不了）、
成员表的**在线状态**按"最近 2 分钟跟服务端说过话"算（没有长连接，这是此刻能做到的最好口径）。
客户端在 `20-main.js` 的「公会（本次重做）」那一段：**连不上云时建会在本机成立**（`remote:false`，
决策 #10 的单机可玩），等能连上时自动**补登记**到服务端（不重复扣号角）。
公会表目前是**内存版**：重新部署就清空 —— 上面那条补登记就是为它准备的自愈。
